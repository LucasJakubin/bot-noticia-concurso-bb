# Bot Notícias

A função do Bot é enviar notícias sobre o concurso do Banco do Brasil uma vez por dia seguindo os seguintes requisitos

# Requisitos

R1	Buscar notícias sobre o concurso do Banco do Brasil ✅
R2	Verificar uma vez por dia, funcionando com o computador desligado ✅
R3	Enviar título, link ✅
R4	Enviar só para Lucas ✅
R5	Enviar “Sem novidades hoje” quando não houver notícia nova ✅
